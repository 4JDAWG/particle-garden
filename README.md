# Particle Garden

A single-file canvas particle playground. Click and drag to plant particles, then watch them react to your cursor.

## Running it

No build step or dependencies — just open [`index.html`](index.html) in a browser.

## Controls

| Mode | Effect |
|---|---|
| **Attract** | Particles pull toward the cursor |
| **Repel** | Particles push away from the cursor |
| **Swirl** | Particles orbit around the cursor |
| **Paint** | Particles drift gently and stay near where they're drawn |

Other controls:

- **Clear** — remove all particles
- **Pause** — freeze the simulation
- **Trail** — adjust how long particle trails linger
